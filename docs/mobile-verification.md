# 手机与弱网验收矩阵

本轮未启动浏览器、未执行真实系统危险动作。组件测试不等同于手机实机验收。

## 共享边界

| 范围 | 现有证据 | 未验收 |
| --- | --- | --- |
| 所有功能页 | URL feature 导航、共享侧栏入口；业务使用 md 默认断点 | 320px 页面级溢出、44px 命中、48px 关键操作、系统缩放 |
| 查询 | TanStack 聚焦与重连刷新；离线提示 | 各域保留缓存的时间标示与 stale 状态逐页审查 |
| 写操作 | 离线发送前拒绝、mutation 不排队重放；任务 requestId 核实 | 各入口重复提交与未知结果矩阵全覆盖 |
| 浮层 | 两层独立历史标识组件回归 | 快速开关、实际历史长度、手机系统返回、执行中关闭 |
| PWA | 构建内容摘要版本、固定静态壳、API 不缓存的受控测试 | 手机安装、独立启动、两版本等待与激活、离线冷启动 |
| 更新 | 写传输/任务/未核实记录保护；编辑作用域保护 | 跨页面草稿及输入瞬间更新竞态 |

## 逐域场景

以下每行都须分别检查加载、空、持续读取错误、离线保留旧数据、恢复前台和必要动作入口。
未运行的项目保持待验收，不能因页面存在而打勾。

| 域 | 必查操作与信息 | 状态 |
| --- | --- | --- |
| 概览 | 刷新结束反馈、旧数据时间、窄屏卡片和可见导航 | 待逐页/实机验收 |
| 文件 | 长路径局部滚动、选择对象与数量、创建/改名/复制/移动/删除、手机键盘遮挡 | 弹窗受控测试通过；实机与全入口待验收 |
| 磁盘增长 | 历史扫描时间、图表局部滚动、定位/废纸篓确认、真实进度 | 任务契约回归通过；图表及权限实测未做 |
| 进程 | 点按详情、选择与结束确认、信号发送不冒充已退出 | 部分组件测试；完整入口待验收 |
| 流量 | 快照时间与实时采样状态区分、批量结果、进程状态未知 | 事务和部分交互测试；手机呈现待验收 |
| 端口 | 点按展开、筛选可达性、结束对象与 busy | 部分组件测试；手机呈现待验收 |
| FRP | 草稿与保存基线、刷新保留编辑、放弃确认、键盘和输入标签 | hook 回归通过；完整草稿生命周期待验收 |
| 系统服务 | 系统权限拒绝、危险影响、执行中入口与状态核实 | 受控动作/接线测试；真实权限未验收 |
| 任务中心 | 最近结果、部分完成对象、未知持续保护、离线不冒充进度 | 组件/HTTP回归通过；手机触控和返回待验收 |

## 验收边界

- 保持已授权的无登录、开发51509/生产51510、HTTPS与局域网访问，不回退产品边界。
- 手机浏览器验证须明确授权并由专用执行者完成，当前未授权也未启动。
- 真实服务重启、杀进程、废纸篓及真实用户文件写入不是自动验证手段。
- 保存每项实际操作、可观察结果和失败证据；测试数量只能作为补充，不能替代本矩阵。
