# 巡检指南（任务 55 兔子浏览器巡检输入材料）

## 0. 这份文档给谁用

**读者**：任务 55 的浏览器巡检执行者（兔子）。

**用途**：拿着这份材料在真实浏览器里逐项走查本仓库（freewind-mac-manager）当天落地的全部改动，记录实际表现与预期不符之处。

**巡检纪律**：

1. **只记录，不改代码**。发现任何问题都写进报告，不要修改仓库文件、不要提交、不要 `git add`。
2. **问题记录格式**（每条都要给全）：
   `页面 / 位置 → 预期 → 实际 → 复现步骤 → 截图 → 宽度档位（320 / 768 / 桌面）`
3. **区分两类问题**：
   - **实现缺陷**：与本文档的「预期」明确不符（例：勾选备份后整行没有底色）。
   - **设计待定**：观感或交互可以更好，但没有明确对照标准（例：某个近似图标不够贴切）——写「设计待定」并给建议候选，不要当成缺陷。
4. **宽度档位**：每个页面至少看一次 320px 与桌面；`md`（768px）是默认断点，涉及布局切换的项要单独看 768。
5. 文中相对路径都是仓库相对路径。

## 1.4 线宽比对方法（浏览器实测）

1. **对照基准**：先看 `ui/**` 官方组件（未改）或 `agent-elements/**` 内的图标——这是正确基准。
2. **比对三处**：左侧边栏全部导航图标（A 批改动最大）；文件页头部（标题 + 新建按钮 + 工具栏）；任意表格的行内图标与行操作菜单图标。
3. **DevTools 看哪里**：Elements 选中业务图标 `<svg>`：
   - Computed / 样式面板看 `stroke-width`，应为 **`2`**（lucide 默认）；出现 `1.5`、`1.75` 说明仍是 hugeicons 或有人散写线宽。
   - Attributes 应看到 `stroke="currentColor"`、`fill="none"`；**不应**看到 hugeicons 的多路径结构与 `primaryColor/secondaryColor`。
4. **回归判据**：同屏业务图标与官方组件图标粗细一致；加载动画旋转时线宽不抖；`prefers-reduced-motion` 打开后动画停止。
5. **反例（记为缺陷）**：某图标明显比旁边细（旧 hugeicons 残留）、图标被裁切、同一语义图标两页粗细不同。

## 1.5 填充型三个（Brain / Bot / Container）专项

| 图标 | 位置 | 步骤 | 通过标准 |
|---|---|---|---|
| `Brain` | AI 助手按钮、助手对话框、AI 工具卡 | 打开助手面板与工具卡，缩小窗口看小尺寸 | 线框清晰不糊成实心；与设置卡图标同粗细 |
| `Bot` | AI 助手入口、概览卡、系统服务空态 | 分别看按钮内（小）与空态（大）两种尺寸 | 大尺寸细节完整；小尺寸仍能辨出机器人轮廓 |
| `Container` | Docker 页标题与容器入口 | 看标题旁与列表空态 | 与同页 `Network`/`Database` 观感一致 |

**判据**：若某处看起来是**实心黑块或半实心**，说明填充被误应用（记为缺陷）；若三者都变成细线框、与改前明显不同，属**预期变化**，只需确认是否可接受。
